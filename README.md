Library Management Database

About

A SQL-based Library Management System developed using MySQL to manage books, authors, members, borrowing, and return records.

Features

- Book and author management
- Member information
- Book issue and return tracking
- Overdue book identification
- Fine calculation
- Borrowing reports

Technologies Used

- MySQL 8.0
- MySQL Workbench
- SQL

SQL Concepts

CREATE, INSERT, SELECT, WHERE, JOIN, GROUP BY, ORDER BY, Subqueries and Aggregate Functions.

Objective

To improve database management skills by developing a library database system using SQL.
